## 主要变化

- 新增：支持查看在线设备列表，并支持下线指定设备
- 修复：登录时校验 CAS 缓存，避免切换账号时使用错误的缓存凭据
- 修复：过长的 daemon 初始化时间
- 改进：优化输出格式，优先使用人类友好输出，可传参输出 json
- 改进：现在可以使用 -version 看版本号了
