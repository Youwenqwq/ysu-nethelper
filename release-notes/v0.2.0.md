# ysunethelper v0.2.0

这是继 v0.1.0 之后的版本，重点改进了登录体验、系统包安装和 daemon 配置流程。
感谢 @CoolestEnoch 参与贡献。

## 主要变化

- `login` 支持 `-u`、`-p` 和 `-s`，也支持终端交互输入账号密码。(#1)
- 在线状态信息补充账户姓名。(#1)
- 普通用户执行 `status`、`login`、`logout` 时不再因为 `/etc` 权限问题失败。
- 增加 Debian、RPM 和 pacman 系统包，并覆盖常用的 amd64、arm64、armv7 架构。
